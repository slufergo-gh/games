# 花磚老厝 數值表

所有數值都在 `config.js`，改完存檔、重新整理網頁就生效。規則預設值與原版桌遊相同。

## 花磚

| 項目 | 設定名稱 | 預設值 | 說明 |
|---|---|---|---|
| 花磚種類 | `tiles` | 鈷藍、鵝黃、牡丹、墨綠、薄荷 | 順序＝牆面第一排由左到右；圖片在 `assets/images/tile_<key>.png` |
| 每色數量 | `tilesPerColor` | 20 | 共 5×20＝100 塊 |

## 窯（工廠）

| 人數 | 窯數量（`factoryCount`） | 每座窯幾塊（`tilesPerFactory`） |
|---|---|---|
| 2 人 | 5 | 4 |
| 3 人 | 7 | 4 |
| 4 人 | 9 | 4 |

人數範圍：`minPlayers` 2、`maxPlayers` 4。

## 計分

| 項目 | 設定名稱 | 預設值 |
|---|---|---|
| 貼磚 | （程式規則） | 單獨 1 分；橫向相連每塊 +1、直向相連每塊 +1，橫直都有連就兩邊相加 |
| 破磚列扣分 | `floorPenalties` | -1、-1、-2、-2、-2、-3、-3（7 格，超過的磚直接丟掉不扣分） |
| 先手牌佔破磚列 | `firstMarkerPenalty` | 是 |
| 完成一條橫排 | `bonusRow` | +2 |
| 完成一條直排 | `bonusColumn` | +7 |
| 集滿一種顏色 5 塊 | `bonusColor` | +10 |
| 終局條件 | `endWhenRowsComplete` | 有人完成 1 條橫排，該回合結束後終局 |
| 同分 | （程式規則） | 完成橫排多的人勝，再同分就並列 |

## 畫面與連線

| 項目 | 設定名稱 | 預設值 |
|---|---|---|
| 過程動畫 | `anim` | 以下為「普通」速度；設定裡「慢」×1.6、「快」×0.55、「關」不播；播放中點一下畫面直接跳到結果 |
| 　被拿的磚亮起 | `anim.highlightMs` | 280 毫秒 |
| 　花磚飛行 | `anim.flyMs` | 520 毫秒 |
| 　多塊磚出發間隔 | `anim.staggerMs` | 90 毫秒 |
| 　結算開始前停頓 | `anim.roundPauseMs` | 700 毫秒 |
| 　每排貼上牆後停頓 | `anim.rowPauseMs` | 650 毫秒 |
| 　破磚每格扣分間隔 | `anim.floorStepMs` | 260 毫秒 |
| 　終局每類加分停頓 | `anim.bonusStepMs` | 1100 毫秒 |
| 　新回合補磚間隔 | `anim.refillStaggerMs` | 35 毫秒 |
| 　飄字顯示 | `anim.popMs` | 1100 毫秒 |
| 　分數滾動 | `anim.scoreRollMs` | 600 毫秒 |
| 通知顯示時間 | `toastMs` | 2600 毫秒 |
| 房間代碼長度 | `roomCodeLength` | 4 個英文字母 |
| 連線代碼前綴 | `peerPrefix` | `hualaocuo-v1-`（改了之後舊版本的房間互不相通） |
| 斷線判定 | （程式） | 12 秒沒有訊息就自動重連；房主 15 秒沒收到心跳就標示「斷線」 |
