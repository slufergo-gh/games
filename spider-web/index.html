說明

目標

  • 上面的蜘蛛網掛著蜘蛛卵囊，蜘蛛會吊著絲一隻一隻垂下來。
  • 把所有卵囊打破就過關，關卡會越來越難。
  • 被蜘蛛碰到、或被毒液打到，就少一台砲台。砲台用完就結束。

操作

  • 手機：按下面的 ◀ ▶ 移動，按「發射」射擊。也可以手指在畫面上左右拖。
  • 電腦：方向鍵 ← → 或 A D 移動，空白鍵射擊，P 或 Esc 暫停。也可以用滑鼠移動、按住左鍵射擊。
  • 設定裡有「自動連發」，打開後不用一直按發射。

小技巧

  • 射斷蜘蛛絲（射蜘蛛上面那條線）：蜘蛛會掉到地上暈一下，這時打牠分數兩倍！但沒打到牠就會爬過來。
  • 白色的蜘蛛網球打到會讓砲台變慢一下，綠色毒液才會扣命。
  • 打破卵囊有時會掉出寶物：雙＝兩發子彈、快＝連射變快、盾＝擋一次、命＝多一台砲台。
  • 紫蜘蛛和綠吐絲蛛吊在半空中時，有時會在那裡拉出彎彎曲曲的蜘蛛絲、結新的網和卵囊，網會一層一層往下把你包圍。看到牠在結網就快點打掉（或射斷牠的絲）；打破新卵囊，那一片網就會掉下來。新卵囊也要打破才能過關。
  • 每 5 關會出現大蜘蛛「蛛后」。

蜘蛛種類

  • 紫蜘蛛：最普通，會上上下下。
  • 橘跳蛛：吊到一半會跳下來亂跳。
  • 綠吐絲蛛：吊在半空中吐網球和毒液，要打兩下。
  • 灰甲蛛：慢慢垂到地上爬過來，要打三下。
