# 傭兵團：屍潮突破 數值表

所有數值都在同資料夾的 `config.js`，改完存檔、重新整理遊戲即可生效。距離單位是公尺（角色身高約 1.8），時間是秒，速度是公尺/秒。

## 整體與關卡

| 項目 | 數值 | config.js 位置 |
|---|---|---|
| 破關模式關數 | 3 | game.campaignStages |
| 道路寬度 | 18（半寬 9） | game.roadHalf |
| 可後退距離 | 從最前進過的位置往回 8 | game.retreatLimit |
| 後退線推進 | 開局 20 秒後，後退線以每秒 1.0 往前推（屍王出現後停止） | game.pushDelay / pushSpeed |
| 紅線（放跑判定） | 後退線再往後 5，跑過就算放跑（不會失敗，只扣分） | game.lineBehind |
| 殭屍放棄追擊 | 越過玩家 4 之後就不再追，直接往下跑 | game.leaveDistance |

| 場上殭屍上限 | 340 | game.maxZombies |

## 過關評價

分數 = 擊殺 x 10 − 放跑 x 20 + 時間獎勵（最低 0 分）。時間獎勵 = (標準時間 − 過關秒數) x 40，不會是負的。

| 關卡 | 標準時間 | S | A | B |
|---|---|---|---|---|
| 第 1 關 | 150 秒 | 7000 | 5000 | 3000 |
| 第 2 關 | 170 秒 | 8750 | 6250 | 3750 |
| 第 3 關 | 190 秒 | 10500 | 7500 | 4500 |

低於 B 是 C。數值在 config.js 的 score。
